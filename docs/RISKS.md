# Aether 风险清单（M0 基线）

> 评级：高 / 中 / 低。状态：已验证 / 缓解中 / 待验证 / 阻塞。
> 安全相关失败一律阻止发布（工程原则 9）。

## R1 加密与密钥（高）

| # | 风险 | 影响 | 缓解 | 状态 |
|---|---|---|---|---|
| R1.1 | 用户清除浏览器数据且未备份密钥 → 历史消息永久不可解密 | 数据丢失 | 安全中心强提示；首次加密会话前引导完成 SSSS+密钥备份；恢复密钥离线保存 | 机制已验证（T05），UI 待 M3 |
| R1.2 | IndexedDB 明文存储密钥被本机恶意软件读取 | 密钥泄露 | `initRustCrypto` 使用 32 字节 `storageKey` 加密存储（T01 已验证错误密钥拒绝）；storageKey 派生自用户凭据经 SSSS，不落明文日志 | 已验证 |
| R1.3 | iOS Safari ITP 对脚本可写存储有 7 天无交互驱逐策略 | 密钥/会话被清 | 主屏幕 PWA 豁免部分限制但仍需实测；密钥备份兜底；M5 专项测试 | 待验证（M5） |
| R1.4 | 自研附件加密偏离 Matrix 规范导致互操作/安全缺陷 | 附件泄露或不可解 | 严格按规范 EncryptedFile（AES-256-CTR+SHA-256，v2），T03b 已验证往返+篡改检测；M4 与 Element 互操作测试 | 部分验证 |
| R1.5 | 把 TLS/DTLS-SRTP 误当通话 E2EE | 通话被 SFU 侧窃听 | M6 必须实测 MatrixRTC 每成员密钥分发与 LiveKit E2EE 状态，验证 SFU 不可解密 | 待验证（M6） |
| R1.6 | 未验证设备加入房间接收密钥 | 中间人 | 房间设置 `onlyAllowTrustedDevices` 评估 + 新设备显著提醒 + 跨签名验证流程（M3） | API 已确认，策略待 M3 |

## R2 准入与账号（高）

| # | 风险 | 影响 | 缓解 | 状态 |
|---|---|---|---|---|
| R2.1 | 邀请码暴力尝试 | 未授权注册 | 仅存哈希、过期时间、尝试次数限制、一次性使用；Synapse 层 uses_allowed 兜底（T05 已验证超额拒绝） | 部分验证 |
| R2.2 | 超过 4 人 | 隐私边界破坏 | 邀请服务全局名额计数（事务锁）+ 注册令牌限量；M1 集成测试 | 待实现（M1） |
| R2.3 | 管理 Token 泄露到前端 | 服务器被完全控制 | 管理 API 仅邀请服务可达；Caddy 不暴露 /_synapse/admin；代码审查门禁 | 设计已定，M1 验证 |
| R2.4 | 联邦/公开注册残留 | 陌生人进入 | `federation_domain_whitelist: []`、registration_requires_token、禁访客、房间邀请制；M1 部署检查脚本逐项断言 | M0 本地配置已用，M1 固化并实测通过 |
| R2.5 | **名额口径分歧（LR-M1-1）**：DESIGN §3.3 发令牌即预占席位且单调不回收，PRD Q4 文字口径为「= Synapse 正式用户数」；令牌发出但未在 60min 内注册会永久占席，4 人系统可能凑不满 4 个真实账号（PRD Q2 不复活、Q4 不支持注销回收） | 容量/可用性：末位成员可能无法注册 | fail-closed，不会放入第 5 人、不破坏密文机密性 → 非安全阻断项。已钉为显式观测断言 `Q6 [LR-M1-1]`；**M2 开工前决策**：(a) 接受并管理员手动换码，或 (b) 增加令牌过期席位回收 + 同步修订 PRD Q2/Q4 与 DESIGN §3.3 | **待用户决策（M1 验收遗留）** |
